You are a senior full-stack developer reviewing a bootstrap plan for a free, self-hosted book publishing system.

## Project Vision

Build "100 Solopreneur Short Stories" as a fully free, deployable book system.

Core requirements from project brief:
- mdBook (Rust static site generator) for book rendering
- GitHub Pages for free hosting (zero cost)
- Stripe for selling/monetizing the book
- Shell scripts for batch story generation
- No paid APIs, no servers, no Streamlit
- Stories: viral essay-style, gripping narrative, Sun Yu-cheng public essay style
- Deploy: user visits URL, reads book, can buy premium version

## Proposed Bootstrap Architecture

### Layer 1: mdBook (Content Engine)
- book.toml — config (title, author, theme)
- src/SUMMARY.md — table of contents (auto-generated by scripts)
- src/stories/*.md — one file per entrepreneur story
- Shell scripts: add-story.sh, batch-generate-stories.sh

### Layer 2: GitHub Pages (Free Hosting)
- .github/workflows/deploy.yml — auto-deploy on git push
- Builds mdBook → static HTML → publishes to gh-pages branch
- URL: https://username.github.io/dynamic-book-generator

### Layer 3: Stripe (Monetization)
- Free chapters: first 10 stories publicly visible
- Paid full book: Stripe Payment Link (no backend required)
- How: Stripe hosted payment page → email delivery of EPUB
- OR: Stripe + Gumroad/Lemon Squeezy as simpler alternative

### Layer 4: Landing Page (First Page)
- Custom index.html OR mdBook intro page
- Shows: book title, 3 sample story excerpts, buy button
- Buy button: links to Stripe Payment Link

### Question 4: GitHub Actions Workflow

**Standard mdBook deploy workflow:**

```yaml
name: Deploy mdBook
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install mdBook
        run: cargo install mdbook
      - name: Build
        run: mdbook build
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./book
```

**Issues:**
- `cargo install mdbook` takes 5-10 minutes (builds from source)
- Better: use pre-built binary or mdBook action

**Fastest GitHub Actions approach for mdBook deploy?**

### Question 5: Story Generation (Shell Scripts)

**add-story.sh** — adds a single story:
```bash
#!/bin/bash
NAME="$1"
SLUG=$(echo "$NAME" | tr ' ' '-' | tr '[:upper:]' '[:lower:]')
FILE="src/stories/$SLUG.md"
cat > "$FILE" << EOF
# $NAME

*Story coming soon...*
EOF
echo "- [$NAME](stories/$SLUG.md)" >> src/SUMMARY.md
echo "Created: $FILE"
```

**batch-generate-stories.sh** — reads names.txt:
```bash
#!/bin/bash
while IFS= read -r name; do
  ./add-story.sh "$name"
done < names.txt
```

**Are these scripts sufficient? What's missing?**
- SUMMARY.md ordering?
- Duplicate detection?
- Git auto-commit after adding?
